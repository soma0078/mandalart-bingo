# 만다라트 빙고 앱 PRD (Product Requirements Document)

## 1. 개요

### 1.1 제품명

**만다라트 빙고 (Mandalart Bingo)**

### 1.2 제품 설명

만다라트 기법을 활용한 목표 설정 및 달성 추적 앱. 9x9 그리드(81칸) 구조로 핵심 목표와 세부 목표를 체계적으로 관리하고, 빙고 게임처럼 달성한 목표를 시각적으로 표시하여 동기부여를 제공한다.

### 1.3 목표 사용자

- 개인 목표 달성을 원하는 일반 사용자
- 팀/조직 단위로 목표를 공유하고 관리하려는 그룹
- 학생, 직장인, 자기계발에 관심 있는 모든 사람

### 1.4 플랫폼

- iOS (iPhone, iPad)
- Android (Phone, Tablet)
- React Native + Expo 기반 크로스 플랫폼 개발

## 2. 만다라트 구조

### 2.1 기본 구조

```
┌─────────────────────────────────────┐
│  [3x3]  │  [3x3]  │  [3x3]  │
│ 세부목표1 │ 세부목표2 │ 세부목표3 │
├─────────────────────────────────────┤
│  [3x3]  │  [3x3]  │  [3x3]  │
│ 세부목표8 │ 핵심목표  │ 세부목표4 │
├─────────────────────────────────────┤
│  [3x3]  │  [3x3]  │  [3x3]  │
│ 세부목표7 │ 세부목표6 │ 세부목표5 │
└─────────────────────────────────────┘
```

### 2.2 계층 구조

1. **핵심 목표 (Core Goal)**: 중앙 3x3 그리드의 정중앙 (1개)
2. **세부 목표 (Sub Goals)**: 핵심 목표 주변 8칸 (8개)
3. **실행 항목 (Action Items)**: 각 세부 목표별 8개씩 (64개)
4. **총 81칸**: 1(핵심) + 8(세부) + 8×8(실행) = 81

## 3. 핵심 기능 (Core Features)

### 3.1 만다라트 생성 및 편집

#### 3.1.1 생성

- 빈 만다라트 새로 만들기
- 템플릿에서 시작하기
- 기존 만다라트 복제하기

#### 3.1.2 편집

- 각 칸 탭하여 텍스트 입력/수정
- 드래그 앤 드롭으로 칸 위치 변경
- 칸별 색상 지정
- 이모지/아이콘 추가 지원
- 메모/설명 추가 (각 칸에 상세 내용 기록)

#### 3.1.3 뷰 모드

- **전체 보기**: 9x9 그리드 한눈에 보기
- **중앙 집중 보기**: 핵심 목표 + 8개 세부 목표만 표시
- **세부 목표 보기**: 특정 세부 목표의 3x3 그리드 확대

### 3.2 진행률 추적

#### 3.2.1 목표 완료 체크

- 각 칸 탭/스와이프로 완료 상태 토글
- 완료된 칸 시각적 표시 (체크마크, 색상 변화)
- 빙고 라인 달성 시 특별 효과

#### 3.2.2 진행률 시각화

- 전체 진행률 퍼센트 표시
- 세부 목표별 진행률 차트
- 히트맵 스타일 진행 현황
- 주간/월간 진행 그래프

#### 3.2.3 빙고 시스템

- 가로/세로/대각선 완료 시 빙고 달성
- 빙고 달성 수 표시
- 빙고 달성 시 축하 애니메이션

### 3.3 알림 및 리마인더

#### 3.3.1 알림 유형

- 일일 목표 리마인더 (커스텀 시간 설정)
- 주간 진행 상황 요약
- 목표 마감일 알림
- 빙고 달성 축하 알림

#### 3.3.2 알림 설정

- 전체 알림 on/off
- 개별 만다라트별 알림 설정
- 알림 시간대 커스터마이징
- 방해금지 시간 설정

### 3.4 템플릿

#### 3.4.1 기본 제공 템플릿

- **자기계발**: 건강, 학습, 재정, 관계 등

## 9. 경쟁 차별화 전략

> 기존 만다라트 앱의 공통 한계: **"9×9 그리드 채우기"에서 멈춤.**
> 그리드를 완성하고 나면 앱을 다시 열 이유가 없다. 목표와 일상 행동 사이의 다리가 없다.
>
> 핵심 포지셔닝: **"만다라트를 채우는 앱이 아니라, 매일 열게 만드는 앱"**

### 9.1 기존 논의 차별점

| # | 포인트 | 설명 | Phase |
|---|--------|------|-------|
| 1 | **빙고 게임화** | 완료 체크가 가로·세로·대각선 빙고를 향한 진행으로 설계. 명확한 "작은 승리"가 도파민 루프와 재방문 동기를 만듦. 동일 구조 경쟁 앱 없음 | 1 |
| 2 | **Momentum 뷰 (오늘의 집중 카드)** | 9×9를 열지 않아도 앱이 먼저 "오늘 뭘 할지"를 제안. 진행률 1위 세부 목표 자동 선택 + 실행 항목 퀵체크. 장기 목표 → 일상 행동 브릿지 | 2 |
| 3 | **AI 기반 집중 목표 추천** | 진행 속도·최근 활동·달성률을 종합해 집중할 세부 목표를 자동 추천. 단순 % 표시를 넘어 능동적 넛지 제공 | 2 |
| 4 | **활동 캘린더 + 스트릭** | GitHub 잔디 스타일 연간 달성 캘린더. 꾸준함이 시각적으로 쌓이며 리텐션에 직접 작용. 만다라트는 연간 도구인데 기존 앱은 진행 축적을 보여주지 않음 | 2 |
| 5 | **PWA 데스크톱 지원** | 경쟁 앱 대부분 모바일 전용. 9×9는 큰 화면에서 오히려 강점. 직장인·학생의 PC 목표 관리 시나리오 커버 | 2 |
| 6 | **오타니 쇼헤이 연계 마케팅** | 만다라트 대중화의 계기. "오타니처럼 목표 세우기" 포지셔닝 + 그의 구조를 참조한 템플릿으로 초기 유입 훅 | 1 |

### 9.2 신규 차별화 포인트

| # | 포인트 | 설명 | Phase |
|---|--------|------|-------|
| 1 | **만다라트 DNA (연간 리포트)** | Spotify Wrapped 포맷으로 연말 목표 결산 카드 생성. 달성 영역·스트릭 최고 기록·빙고 패턴을 시각화 후 SNS 공유 유도. Wordle식 바이럴 루프로 자연 획득 채널화 | 3 |
| 2 | **목표 시간 여행 (스냅샷 아카이브)** | 만다라트의 시점별 스냅샷 저장 → "1월의 나 vs 6월의 나" 비교. 목표가 어떻게 진화했는지 보는 경험은 기존 어떤 앱도 제공하지 않음. 장기 사용자를 만드는 강력한 훅 | 3 |
| 3 | **책임 파트너 시스템** | 특정 실행 항목을 링크로 공유 → 친구가 "완료 확인" 버튼을 눌러줌. 앱 없이 링크만으로 체크 가능. 혼자 쓰는 도구에서 관계 기반 도구로 확장, 바이럴 획득 포인트 | 2 |
| 4 | **모멘텀 스코어** | 완료율(%)은 과거 지표. 최근 활동 속도·연속 달성·마지막 체크 이후 경과 시간을 종합한 동적 점수. "건강 목표 모멘텀이 떨어지고 있어요" 형태로 재참여 유도. 기존 진행률 데이터로 즉시 구현 가능 | 2 |
| 5 | **만다라트 간 골 연결 (목표 생태계)** | 서로 다른 만다라트의 셀을 연결. "개인 성장" 만다라트의 독서 셀 ↔ "독서 목표" 만다라트 연동. 멀티 보드 사용자에게 단순 목록이 아닌 연결된 목표 시스템으로 포지셔닝 | 3 |
