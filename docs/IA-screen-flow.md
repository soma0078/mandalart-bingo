# 만다라트 빙고 — IA & 스크린 플로우

> 작성일: 2026-04-24 / 최종 수정: 2026-04-24
> Phase 기준: Phase 1 (MVP) 중심, Phase 2 이상 항목은 별도 표기

## 1. 정보 구조 (Information Architecture)

```
📱 만다라트 빙고
│
├── [진입] 스플래시 & 온보딩
│   ├── 스플래시 (로고 + 로딩)
│   ├── 온보딩 슬라이드 (최초 1회, skip 가능)
│   │   ├── Step 1: 만다라트란? (개념 소개)
│   │   ├── Step 2: 핵심 목표 → 세부 목표 구조 설명
│   │   ├── Step 3: 빙고 달성 시스템 소개
│   │   └── Step 4: 시작하기 CTA
│   └── [Phase 2] 소셜 로그인 (Apple / Google / Kakao)
│
├── [탭 1] 홈
│   ├── 만다라트 0개 — Empty State
│   │   └── "첫 만다라트 만들기" CTA
│   ├── 만다라트 1개 — 해당 만다라트 바로 표시 (3×3)
│   │   ├── 뷰 모드 스위치 (간략히 / 전체)
│   │   └── 메인 지정 UI 없음 (자동)
│   ├── 만다라트 여러 개 — 메인으로 지정된 만다라트 표시 (3×3)
│   │   ├── 상단 만다라트명 탭 → 만다라트 전환 모달
│   │   └── 뷰 모드 스위치 (간략히 / 전체)
│   ├── [Phase 2] 홈 — Momentum 뷰 (진행률 기반 자동 집중 추천)
│   │   ├── 보드 스위처 칩 행 — 보유 만다라트 + 달성률 가로 나열, 탭으로 전환
│   │   ├── 히어로 포커스 카드 — 선택된 만다라트의 진행률 1위 세부 목표 자동 표시
│   │   │   ├── 세부 목표명 + 완료율 링 + 실행 항목 리스트
│   │   │   └── 만다라트 전환 시 카드 콘텐츠 교체 (9×9 없이 "오늘 할 일" 제안)
│   │   └── 세부 목표 현황 미니 그리드 (3×3 축소 + 셀별 진행률 바)
│   └── FAB (+) — 새 만다라트 만들기 (항상 노출)
│
├── [스택] 만다라트 뷰어 — 홈 또는 내역에서 진입
│   ├── 3×3 모드 (default)
│   │   ├── 핵심 목표 박스 탭 → 바텀시트
│   │   └── 세부 목표 박스 탭 → 드릴다운 뷰 (세부 3×3)
│   │       └── 실행 항목 박스 탭 → 바텀시트
│   ├── 9×9 모드
│   │   └── 모든 박스 탭 → 바텀시트
│   ├── 진행률 바 (하단 고정)
│   └── 상단 우측 메뉴 (⋮)
│       ├── 이름 변경
│       ├── 메인으로 설정 (만다라트 여러 개일 때만 노출)
│       ├── [Phase 2] 공유 (이미지/링크)
│       ├── 복제
│       └── 삭제
│
├── [탭 2] 통계
│   ├── 전체 진행률 요약 (퍼센트 + 빙고 수)
│   ├── 만다라트별 진행률 목록
│   ├── 기간별 달성 그래프 (주간 / 월간)
│   └── 빙고 달성 히스토리
│
├── [탭 3] 내역
│   ├── 생성했던 만다라트 전체 목록
│   ├── 메인 지정 표시 (★ 뱃지)
│   ├── 필터 (진행중 / 완료 / 전체)
│   ├── FAB (+) — 새 만다라트 만들기
│   └── 각 항목 탭 → 만다라트 뷰어로 이동
│
└── [탭 4] 설정
    ├── 앱 테마 (라이트 / 다크 / 시스템)
    ├── 테마 색상 선택 (색상 팔레트)
    ├── [Phase 2] 알림 설정
    │   ├── 알림 on/off
    │   └── 리마인더 시간 설정
    ├── 데이터 관리 (로컬 백업/복원)
    ├── [Phase 2] 계정 관리
    └── 앱 정보 (버전, 오픈소스 라이선스)
```

## 2. 탭 바 구조

| 탭  | 아이콘 | 레이블 | 비고               |
| --- | ------ | ------ | ------------------ |
| 1   | 🏠     | 홈     | 메인 만다라트 표시 |
| 2   | 📊     | 통계   | 진행률/달성 분석   |
| 3   | 📋     | 내역   | 전체 만다라트 목록 |
| 4   | ⚙️     | 설정   | 테마, 데이터       |

## 3. 스크린 플로우

### 3-1. 최초 실행 플로우

```
앱 실행
  │
  ▼
스플래시 (1.5초)
  │
  ├── 최초 실행 여부 체크
  │
  ├── [최초] 온보딩 슬라이드
  │       │
  │       ├── Slide 1: "만다라트로 꿈을 구체화하세요"
  │       │           (9×9 그리드 개념 시각적 설명)
  │       ├── Slide 2: "핵심 목표 하나, 세부 목표 여덟 개"
  │       │           (구조 다이어그램 + 예시)
  │       ├── Slide 3: "완료할수록 빙고가 완성돼요"
  │       │           (빙고 달성 애니메이션 프리뷰)
  │       └── Slide 4: "시작하기" 버튼
  │                   (skip 버튼 상단에 항상 노출)
  │
  └── [재실행] 홈으로 바로 이동
```

### 3-2. 만다라트 생성 플로우

```
홈 Empty State CTA  또는  내역 탭 FAB(+) 탭
  │
  ▼
만다라트 이름 입력 (모달)
  ├── 이름 입력 후 "만들기" 탭
  └── 취소
        │
        ▼
      [Phase 2] 생성 방식 선택
        ├── "빈 만다라트로 시작" → 뷰어 진입 (빈 3×3)
        └── "템플릿으로 시작"
              │
              ▼
          템플릿 목록 → 미리보기 → "이 템플릿 사용"
              │
              ▼
          뷰어 진입 (템플릿 내용 채워진 3×3)

※ Phase 1: 이름 입력 후 바로 빈 만다라트 뷰어 진입
※ 첫 만다라트 생성 시 자동으로 메인 지정
```

### 3-3. 홈 — 만다라트 전환 플로우 (여러 개일 때)

```
홈 — 상단 만다라트명 탭
  │
  ▼
만다라트 전환 모달 (목록)
  ├── 현재 메인: ★ 표시
  ├── 다른 만다라트 탭 → 홈 뷰 전환 (메인 변경 없음, 임시 보기)
  └── "메인으로 설정" 탭 → 해당 만다라트를 메인으로 저장
        │
        ▼
      홈에 새로운 메인 만다라트 표시

※ 메인 설정은 뷰어 상단 ⋮ 메뉴에서도 가능
```

---

### 3-4. 목표 탭 플로우 — 3×3 모드

```
홈 or 뷰어 (3×3 모드)
  │
  ├── 핵심 목표 박스 탭
  │       │
  │       ▼
  │   바텀시트 (핵심 목표 편집)
  │   • 제목 입력
  │   • 메모 입력 (선택)
  │   • 완료 여부 체크
  │   • [저장] [삭제]
  │       │         │
  │     저장        삭제 확인 얼럿 → 확인 시 내용 초기화
  │       │
  │   바텀시트 닫힘 / 뷰어 갱신
  │
  └── 세부 목표 박스 탭
          │
          ▼
      드릴다운 뷰 (해당 세부 목표 3×3)
      ┌───────────────────────────┐
      │  ← [세부 목표명]           │
      │                           │
      │  ┌───┬───┬───┐            │
      │  │ A │ B │ C │  ← 실행 항목 8개
      │  ├───┼───┼───┤            │
      │  │ H │세부│ D │            │
      │  ├───┼───┼───┤            │
      │  │ G │ F │ E │            │
      │  └───┴───┴───┘            │
      │                           │
      │  진행률: 3/8               │
      └───────────────────────────┘
          │
          └── 실행 항목 박스 탭
                  │
                  ▼
              바텀시트 (실행 항목 편집)
              • 제목 입력
              • 완료 여부 체크
              • 메모 입력 (선택)
              • [저장] [삭제]

※ 핵심 목표 미입력 상태에서 세부 목표 탭 시
   → 토스트: "먼저 핵심 목표를 입력해주세요" (블로킹 없음, 소프트 가이드)
```

---

### 3-5. 목표 탭 플로우 — 9×9 모드

```
뷰어 — 9×9 모드 전환
  │
  └── 모든 박스 탭 → 바텀시트 (목표 유형에 따라 내용 다름)
        ├── 핵심 목표: 제목 + 메모 + 완료 체크
        ├── 세부 목표: 제목 + 메모 + 완료 체크
        └── 실행 항목: 제목 + 메모 + 완료 체크
              │
          [저장] / [삭제]
```

---

### 3-6. 뷰 모드 전환 플로우

```
만다라트 뷰어 (홈 또는 스택 뷰어)
  │
  └── 상단 스위치 토글
        │
        ├── 간략히 보기 (3×3, default)
        │   • 핵심 목표 중앙 + 세부 목표 8칸
        │   • 셀 크기 크고 텍스트 가독성 우선
        │   • 세부 목표 탭 → 드릴다운
        │
        └── 전체 보기 (9×9)
            • 81칸 전체 표시
            • 핀치 줌 지원
            • 세부 목표 영역 구분 배경색 처리
            • 모든 박스 탭 → 바텀시트
```

### 3-7. 빙고 달성 플로우

```
실행 항목 완료 체크 (바텀시트 저장)
  │
  ├── 빙고 라인 미달성 → 진행률 갱신만
  │
  └── 빙고 라인 달성
        │
        ▼
    [Phase 2] 빙고 달성 축하 애니메이션 (오버레이)
        │
        ▼
    "빙고! {세부 목표명} 달성" 메시지
        │
        ▼
    [닫기] or 3초 후 자동 닫힘
        │
        ▼
    통계 탭 — 빙고 히스토리에 기록

※ Phase 1: 애니메이션 없이 진행률 갱신 + 토스트 메시지로 처리
```

---

### 3-8. 통계 화면 플로우

```
탭 바 → 통계
  │
  ├── 전체 진행률 카드 (퍼센트 + 완료 셀 수/81)
  ├── 빙고 달성 현황 (가로/세로/대각선 별)
  ├── 만다라트별 진행률 목록
  │   └── 탭 → 해당 만다라트 뷰어로 이동
  └── 기간 필터 (주간 / 월간)
      └── 달성 그래프 (바 또는 라인 차트)
```

---

### 3-9. 설정 화면 플로우

```
탭 바 → 설정
  │
  ├── 앱 테마
  │   └── 라이트 / 다크 / 시스템 선택 → 즉시 적용
  │
  ├── 테마 색상
  │   └── 색상 팔레트 선택 → 그리드 포인트 색상 즉시 반영
  │
  ├── [Phase 2] 알림 설정
  │   ├── 알림 권한 미허용 시 → 시스템 설정 이동 안내
  │   ├── 알림 on/off 토글
  │   └── 리마인더 시간 설정 (타임피커)
  │
  └── 데이터 관리
      ├── 로컬 백업 → 파일 저장
      └── 백업 복원 → 파일 선택 → 덮어쓰기 확인 얼럿
```

## 4. 빈 상태 (Empty State) 정의

| 화면        | 빈 상태 조건     | 표시 내용                               |
| ----------- | ---------------- | --------------------------------------- |
| 홈          | 만다라트 0개     | "첫 만다라트를 만들어보세요" + 생성 CTA |
| 통계        | 만다라트 0개     | "만다라트를 만들면 통계가 쌓여요"       |
| 내역        | 만다라트 0개     | "아직 만든 만다라트가 없어요"           |
| 드릴다운 뷰 | 실행 항목 미입력 | 셀 내부에 "+ 탭해서 입력" 힌트 텍스트   |
| 3×3 뷰      | 목표 미입력      | 셀 내부에 "+ 탭해서 입력" 힌트 텍스트   |

## 6. 확정된 UX 결정 사항

| #   | 항목                    | 결정                                                                       |
| --- | ----------------------- | -------------------------------------------------------------------------- |
| 1   | 저장 방식               | 바텀시트 내 **저장 버튼** 탭으로 명시적 저장                               |
| 2   | 세부 목표 탭 인터랙션   | 3×3에서 세부 목표 탭 → **드릴다운 뷰** 진입, 실행 항목 탭 → 바텀시트       |
| 3   | 온보딩 재진입           | **제공하지 않음** (최초 1회만)                                             |
| 4   | 만다라트 이름 입력 시점 | **생성 시점** (모달에서 이름 입력 후 생성)                                 |
| 5   | 핵심 목표 미입력 가이드 | **소프트 가이드** (블로킹 없이 토스트 메시지)                              |
| 6   | 홈 탭 구조              | 메인 만다라트 표시. 1개면 자동 표시, 여러 개면 **메인 지정** 기능으로 선택 |
